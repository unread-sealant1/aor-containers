The following is the full report on the functionality and integration of the admin panel.

### 1. Page-by-Page Audit

| Page | Purpose | Primary API Endpoints | Status |
| :--- | :--- | :--- | :--- |
| **Dashboard** | High-level stats & recent activity | `GET /admin/stats` | Fully Functional |
| **Product List** | Inventory management & filtering | `GET /admin/containers`, `PATCH /admin/containers/publish`, `DELETE /admin/containers/:id` | Fully Functional |

| **Enquiries** | Manage customer product leads | `GET /admin/enquiries`, `PATCH /admin/enquiries/:id`, `DELETE /admin/enquiries/:id` | Fully Functional |

| **Media Library** | Global image overview | `GET /admin/media` | Read-Only (Deletion 501) |

### 4. Data Flow Analysis
*   **Type Matching**: Frontend interfaces (e.g., `ProductFormData` in `ProductForm.tsx`) align closely with Mongoose models. 
*   **Inconsistency**: `ProductForm.tsx` (Active) uses `category` as a string, while `AddContainer.tsx` (Stale) uses `categoryId`.
*   **Auth Pattern**: Most pages use `apiClient` (axios) which injects the Bearer token. However, `Orders.tsx` and `OrderDetail.tsx` use raw `fetch`, meaning they would fail authentication if they were reachable.

---

### 5. Broken / Missing / Stale Features

*   **Dead Pages**: `Orders.tsx` and `OrderDetail.tsx` are completely unreachable as they are missing from `App.tsx` routes and `AdminLayout.tsx` navigation.
*   **Broken UI**: In `Messages.tsx`, the **"Send Reply"** button lacks an `onClick` handler; it is visually present but non-functional.
*   **Backend 501s**: Several endpoints in `adminController.ts` return `501 Not Implemented`, including:
    *   `getRecentOrders`, `getRecentActivity` (Dashboard components).
    *   Category management (`createCategory`, `updateCategory`, `deleteCategory`).
    *   Admin user management (`getAdmins`, `createAdmin`, `deleteAdmin`).
*   **Restricted Actions**: `mediaController.deleteMedia` returns a 501, making the media library read-only.
*   **Stale Files**: `AddContainer.tsx` is a redundant, unused version of `ProductForm.tsx` and should be removed.
